# 片刻文具局

面向 15–25 岁年轻人的互动学习文具品牌网站。它包含时间惊喜开场、商品陈列、随机今日签、水面涟漪、点击粒子、本地随机歌单和品牌信息标签页。

## 浏览方式

- 鼠标滚轮：桌面端一次滚动一整页。
- 右侧页码：点击 01–04 直接跳转。
- 页内按钮：点击每页底部圆形箭头进入下一页。

## 预览

直接双击 `index.html`，或在此目录运行：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 上线前要替换

- `index.html` 中的电话、邮箱、微信和退货地址。
- 演示商品名称、价格、材质、尺寸、执行标准、库存及退换货规则。
- 音乐可通过网页右上角按钮选择本机文件；浏览器禁止未交互自动播放，因此首次播放必须点击。
